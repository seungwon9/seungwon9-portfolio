# Seungwon Developer Portfolio

문제 해결 과정과 판단 근거를 중심으로 구성한 개발자 포트폴리오입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검사

```bash
npm run typecheck
npm run lint
npm run build
```

## 콘텐츠 수정

- 프로젝트 데이터: `src/data/projects.ts`
- 프로필: `src/data/profile.ts`
- 경력: `src/data/experience.ts`
- 역량 그룹: `src/data/skills.ts`
- 프로젝트 타입: `src/types/project.ts`

현재 프로젝트 세부 내용, 성과, 경력, 기술 목록, 연락처와 미디어는 placeholder 상태입니다. 검증된 정보만 추가합니다.
